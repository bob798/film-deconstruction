## 这是什么 What is this

这是一个开源的**电影深度拆解库**。挑选在视听语言、叙事或思想上有高密度的影片，用统一模板把"看过一遍的印象"转写成可检索、可引用、可学习的结构化笔记。

适合：

- **影迷 / 影评写作者** —— 看一部电影的镜头、调度、母题如何被组织
- **创作者 / 学生** —— 拆出"可复制 vs 不可复制"的导演方法论
- **研究者** —— 带时间码的关键场景分析，可回到原片逐格核对

> 姊妹项目：[AI 创始人 & 研究员深度访谈分析](https://github.com/bob798/ai-founder-interviews)（同样的深度拆解方法，用于长访谈）。

## 拆解方法 Methodology

每部影片遵循统一模板（完整版见 **[TEMPLATE.md](./TEMPLATE.md)**），输出 **9 大块结构**：

1. **影片信息块**——片名 / 导演 / 年份 / 片长 / 类型 / 获奖 / 资源
2. **I. 上帝视角**——导演意图、核心主题、时代与创作坐标
3. **II. 核心看点**——按观影价值排序的若干条
4. **III. 视听语言拆解**——镜头与构图 / 场面调度 / 色彩与光 / 声音与配乐 / 剪辑节奏
5. **IV. 叙事结构**——时间线、视角、结构图
6. **V. 母题与符号**——反复出现的意象与隐喻
7. **VI. 关键场景逐格分析**——3–5 个高密度场景，带时间码与截图位
8. **VII. 导演方法论**——可复制 vs 不可复制（✅ / ❌ / ⚠️）
9. **VIII. 影史坐标与互文** + **局限性说明**

**质量要求**：综合分 ≥ 8/10（完整性 / 论证 / 启发性）。
**设计原则**：区分"画面事实 vs 分析者解读"、避免硬贴理论标签、关键判断给出可回溯的时间码、客观声明主观局限。

## 如何贡献 Contributing

1. 复制 [`TEMPLATE.md`](./TEMPLATE.md) 到 `导演-片名-年份/analysis.md`（kebab-case 目录名）。
2. 按 9 大块填写，关键场景标注时间码。
3. 在本 README 的[拆解索引](#拆解索引-index)登记一行。
4. 提交 PR。
